Alana

Aplikasi pembaca manhwa untuk menemukan judul, menyimpan favorit, dan melanjutkan bacaan dengan nyaman.

Dokumen

  • Kebijakan Privasi — data yang kami kumpulkan, cara penggunaannya, dan hak Anda.
  • Hapus Akun — cara menghapus akun dan seluruh data Anda.

Tentang aplikasi

Alana adalah pembaca komik. Data akun dan riwayat baca disimpan di server Supabase agar bisa disinkronkan antar perangkat, sementara cache gambar dan chapter yang sudah diunduh tersimpan hanya di perangkat Anda.

Alana tidak memuat iklan dan tidak memakai SDK analitik atau pelacak pihak ketiga. Sumber metadata dan gambar chapter berasal dari api.shngm.io dan assets.shngm.id.
